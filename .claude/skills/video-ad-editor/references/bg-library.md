# 🎧 مكتبة الخلفيات الحلال

خلفيات صوتية جاهزة (أصوات بشرية بلا موسيقى — أناشيد خلفية) بمجلد `halal-audio/` بمستودع قت هب الخاص
بالمستخدم — نفس المستودع اللي ينزل منه البلقن. كل ملف علوه موحّد ‎-16 LUFS وصمت طرفيه مقصوص،
وبالفهرس `catalog.json`: المدة، السرعة، الطاقة، هل الإيقاع واضح (للمونتاج)، نقطة بداية على النبضة،
والطابع والتقييم اللي حطّه المستخدم بأذنه.

**المكان ينلقى وحده** — لا تمرّر مسار: `BG_LIB` ← المستودع نفسه (جلسة السحابة، أو نسخته على الجهاز)
← `halal-audio/` بمجلد المشروع ← نسخة البلقن من قت هب (`~/.claude/plugins/marketplaces/*/halal-audio`) ← `~/.claude/halal-audio`.
تبي تتأكد؟ `python scripts/42_bg_audio.py where`.

## متى
- **ما عطاك ملف صوتي بالخلفية والوضع يحتاجه** — المونتاج دايماً (بدونه ساكت)، أو قال «حط خلفية».
- **عطاك ملفه؟** استخدمه كما هو بـ`bg-audio.mp3` — المكتبة بديل، مو فرض.
- **ريل كلام / بودكاست:** الخلفية اختيارية — اعرضها مرة وحدة: «تبي خلفية صوتية؟ عندي 3 تناسب».
- **موشن:** بلا خلفية افتراضياً (`references/motion-mode.md`) — بس لو طلب.

## الخطوات

### 1) اقترح 3 وخلّه يسمع
```bash
python scripts/42_bg_audio.py suggest <work> --use reel|montage|motion|podcast [--mood calm] [--dur 30]
```
| | |
|---|---|
| `--use` | `reel` هادي ما يزاحم الكلام · `montage` إيقاع واضح وطاقة أعلى · `motion` إيقاع + طاقة متوسطة · `podcast` هادي وطويل |
| `--mood` | لو قال «هادية/حماسية…»: `calm` هادئ · `inspiring` ملهم · `energetic` حماسي · `reflective` تأملي · `epic` ملحمي |
| `--dur` | مدة الفيديو. تنقرا وحدها من `ad-final.mp4` / `montage.mp4` / `caps.json` — بالمونتاج قبل التركيب عطه نفس `plan --dur` |

يطلع 3 معاينات 20 ث بـ`<work>/bg-previews/` (`A-…` · `B-…` · `C-…`).
**أرسلها له يسمعها** (SendUserFile) مع سطر لكل وحدة: الاسم، المدة، الطابع. ⛔ لا تختار عنه.

### 2) اختياره ← `bg-audio.mp3`
```bash
python scripts/42_bg_audio.py pick <work> B          # أو رقم الملف: pick <work> 07
```
- يكتب `<work>/bg-audio.mp3` يبدأ على نبضة، بطول الفيديو.
- الفيديو أطول من الملف؟ يلفّه بتلاشٍ متقاطع 2 ث (بلا قفزة مسموعة).
- `--from 0` يبدأ من أول الملف بدل نقطة النبضة.
- `bg-audio.json` = المصدر (الاسم، الفنان، الملف الأصلي) — للذكر والحقوق.

### 3) كمّل خط الوضع كما هو
- **الريل / البودكاست:** `06b_master.sh` يلقاه ويخفّضه وقت الكلام. العلو موحّد، فـ`BG_GAIN` الافتراضي (0.28) يمشي على كل الملفات. يزاحم الكلام؟ `BG_GAIN=0.2`.
- **المونتاج:** الخلفية **قبل** `plan` — `beat.py` على `bg-audio.mp3` ← `plan … --beats` (`references/montage.md` §4)، ثم `06b_master.sh`.
- **الموشن:** بدل `pick` حط بـ`project.json`: `"music": {"file": "lib:07"}` وشغّل `motion/audio.py <المشروع>` **بلا** `--no-bed`.
  - الافتراضي معه `level: -14` و`duck: -10` (الأصوات البشرية تزاحم الكلام أكثر من الخلفية المركّبة).
  - `music.start` يغيّر نقطة البداية. ⚠️ الملف ما يتبع `sections` التايملاين — هذي للمركّبة بس.

## صفحة التصنيف — مرة وحدة، وكل ما تنضاف ملفات
```bash
python scripts/42_bg_audio.py page          # يفتح http://127.0.0.1:8793
```
يسمع ويصنّف: الطابع (أزرار أو 1-5)، تقييم ★، الإيقاع واضح/لا، إخفاء، اسم، ملاحظة —
ينحفظ مباشرة، و`suggest` يمشي عليه. الصفحة على الجهاز بس (127.0.0.1) — ما تنفتح على الشبكة.
`list` يطلع «صنّفت 0»؟ اقترح عليه الصفحة — بدون تصنيف، الاقتراح بالإيقاع والطاقة بس.

## المزامنة بين أجهزته
- الصفحة تجيب تصنيف أجهزته الثانية لما تنفتح، وزر **«مزامنة مع قت هب»** يرفع تصنيف هالجهاز.
- من الطرفية: `python scripts/42_bg_audio.py sync` (أو `--pull` يجيب بس).
- كل تصنيف ينحفظ احتياطياً بـ`~/.claude/halal-audio-tags.json` — لو انعادت نسخة البلقن قبل المزامنة ما يضيع، والأحدث يفوز.
- ⛔ **قبل تحديث البلقن** (`claude plugin marketplace update halal-video`) زامن أول.

## ملفات جديدة — بنسخة المستودع على جهازه بس
بالمستودع (`git clone` لـ`video-edit-halal`)، حط الملفات بمجلد المصدر (`catalog.json ← source_dir`) وأعد:
```bash
python .claude/skills/video-ad-editor/scripts/42_bg_audio.py build "<مجلد الملفات>"
python .claude/skills/video-ad-editor/scripts/42_bg_audio.py sync      # يرفع الملفات الجديدة والفهرس
```
اللي ما تغيّر ما ينعاد، والتصنيف يبقى. بعدها بأجهزته الثانية: `claude plugin marketplace update halal-video` و`claude plugin update Video-Edit@halal-video`.

## بجلسة السحابة (claude.ai/code)
المستودع نفسه هو مجلد الجلسة: السكلات من `.claude/skills/`، والمكتبة `halal-audio/` تنلقى وحدها،
وhook البداية ينزّل ffmpeg. `page` ما يشتغل هناك (ما فيه متصفح) — `list` / `suggest` / `pick` بس، والمعاينات
يحمّلها من فرع الجلسة. التفاصيل بـ`CLAUDE.md` بجذر المستودع.

## ⛔ قواعد
1. **سمّها «خلفية صوتية» لا «موسيقى»** (القاعدة 9 بـSKILL.md).
2. **هو يختار بأذنه** — لا تختار عنه، ولا تحط خلفية ما سمعها.
3. **الأصل ما ينلمس** — المكتبة نسخة معالجة، والمصدر بمجلده.
4. **ملف بلا فنان معروف** (`artist` فاضي بالفهرس) ولإعلان تجاري؟ نبّهه يتأكد من حقوقه.
5. **المخفي ما ينقترح،** وأقل من 15 ث «لمحة» — ما تنقترح خلفية.

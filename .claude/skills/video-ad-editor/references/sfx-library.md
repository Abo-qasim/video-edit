# 🔔 مكتبة المؤثرات الحلال (halal-sfx)

مؤثرات صوتية حقيقية **بلا موسيقى أبداً** — أصوات اليوتيوبرز المعروفة، اختارها المستخدم بأذنه بعد فرز آلي
(YAMNet: أي صوت فيه موسيقى ≥ 50% انشال). بلقن **halal-sfx** رفيق هالبلقن، ينزل من حسابه بـclaude.ai؛
`scripts/44_sfx_lib.py` يلقاه وحده (`where`).

| التصنيف | وش فيه | نقطة الربط |
|---|---|---|
| `whoosh` | ووش/انتقال (8) | الذروة على اللحظة |
| `suspense` | مفاجأة/شوك (2) — تكتكة ساعة و«Shocked» | الذروة |
| `voice` | أصوات ميمز: bruh، nope، uh huh، awww، pew (6) | البداية |
| `ui` | نقرة، تكة، كتابة، بيب، دفع (6) | البداية |
| `camera` | كاميرا وفلاش (4) | البداية |
| `hit` | ضربة، كسر عظم (3) | البداية |
| `game` | Minecraft drink، إجابة غلط (2) | البداية |
| `awkward` | صمت محرج/صرصور الليل (2) | البداية |

`python scripts/44_sfx_lib.py list` يطبع الأرقام (`whoosh-04`…) · `play <work> <رقم>` ينسخه يسمعه.

## الريل — `sfx.json` (الخطوة 8 بـSKILL.md)
```json
{ "outro": 5.2, "whoosh_up": [3.1], "lib": [[7.85, "whoosh"], [12.4, "suspense-04"], [20.1, "voice", 0.8]] }
```
- `[ثانية، تصنيف أو رقم، قوة؟]` — التصنيف يختار صوت ثابت (نفس الفيديو = نفس الصوت)، والرقم صوت بعينه.
- القوة 1 = ذروة ‎-18 dBFS (القاعدة ١). تنخلط مع المؤثرات المركّبة بنفس الملف.

## الموشن — `<proj>/sfx.json`
```json
[{ "type": "lib:whoosh", "at": "scene:s2" }, { "type": "lib:suspense-04", "at": "line:l3", "gain": 0.8 }]
```
نفس `at` و`gain` و`pan` حق المؤثرات المركّبة. الذروة نفس ذروتها (0.8).

## ⛔ قواعد
1. **القاعدة ١ تبقى:** لحظة لها معنى، 15 بالدقيقة بالكثير — المكتبة مو رخصة للرشّ.
2. **أصوات الميمز (`voice`) بحذر:** مرة أو مرتين بالفيديو، وبمكان يضحك فعلاً.
3. **الحقوق:** أصوات مجتمعية مصدرها غير معروف — لإعلان تجاري أو قناة تربح نبّهه.
4. **إضافة أصوات:** نفس الخطوات — فرز YAMNet ثم صفحة «مقبول/مرفوض» (`43_sfx.py review`) — ثم ارفع إصدار
   `halal-sfx/.claude-plugin/plugin.json`.

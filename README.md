مستودع واحد خاص يشغّل البلقن على **أي جهاز** وبـ**جلسات السحابة**:

| المجلد | |
|---|---|
| `.claude/skills/` | البلقن نفسه (5 سكلات: الريل، الموشن، البودكاست، المونتاج، الكفر) — نسخة video-edit 6.0.1 + إضافاتنا |

## 💻 على أي كمبيوتر (الجهاز الحالي، اللابتوب، أي جهاز ثاني)

**مرة وحدة:**
1. ثبّت [Claude Code](https://code.claude.com) و[Git for Windows](https://git-scm.com/download/win) (فيه مدير كلمات المرور).
2. سجّل دخول قت هب بجهازك مرة وحدة:
   ```bash
   git ls-remote https://github.com/Abo-qasim/video-edit-halal.git
   ```
   تطلع نافذة تسجيل دخول قت هب ← سجّل، وخلاص (ينحفظ).
3. ثبّت البلقن (الوقت الأطول لأن المستودع ~210 ميقا):
   ```bash
   claude plugin marketplace add https://github.com/Abo-qasim/video-edit-halal.git
   ```
   ```bash
   claude plugin install Video-Edit@halal-video
   ```
   الإنترنت بطيء ووقف عند «timed out after 120s»؟ ارفع المهلة وأعد الأمر الأول:
   - PowerShell: `$env:CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS = "600000"`
   - Git Bash: `export CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS=600000`
4. أعد تشغيل Claude Code. أول ما تطلب مونتاج، كلود يكمّل تنزيل الأدوات (ffmpeg، بايثون…) بنفسه.

> لو عندك بلقن **video-edit** السحابي مفعّل من حسابك بـclaude.ai — وقّفه، عشان ما يتكرر البلقن.

**التحديث** (بعد أي تعديل بالمستودع):
```bash
claude plugin marketplace update halal-video
```
```bash
claude plugin update Video-Edit@halal-video
```

## ☁️ بالسحابة (claude.ai/code — من اللابتوب أو الجوال)

1. افتح [claude.ai/code](https://claude.ai/code) ← اختر المستودع **video-edit-halal**.
   ما يطلع؟ ثبّت [تطبيق Claude على قت هب](https://github.com/apps/claude) واختر هالمستودع.
2. ابدأ الجلسة — السكلات والمكتبة جاهزة، وffmpeg ينزل وحده أول الجلسة (دقيقة تقريباً).
3. **أسرع (اختياري):** بإعدادات البيئة ← *Setup script* ← الصق محتوى `.claude/cloud-setup.sh` — ينحفظ بالكاش.

**الملفات بالسحابة:**
- المقاطع: ارفعها بمجلد `work/<اسم>/` (commit من جهازك)، أو أعطه رابط تحميل مباشر. ⛔ قت هب يرفض أي ملف فوق 100 ميقا.
- التسليم: كلود يحط الفيديو النهائي بفرع الجلسة، وتحمّله من قت هب.
- **أنسب شي للسحابة:** فيديوهات الموشن (من نص، بلا تصوير) والكفرات والمونتاج القصير.
  المونتاج الثقيل بمقاطع كبيرة؟ على الكمبيوتر — أو شغّل الجلسة على جهازك وتحكّم فيها من اللابتوب/الجوال بـ[Remote Control](https://code.claude.com/docs/en/remote-control).
- التفريغ بالسحابة قد يحتاج شبكة البيئة **Full** (تنزيل موديل وِسبر).

## 🎧 المكتبة الصوتية

- **التصنيف بأذنك:** بأي كمبيوتر، قل لكلود «افتح صفحة مكتبة الخلفيات» — تسمع وتصنّف (هادئ · ملهم · حماسي · تأملي · ملحمي).
- **المزامنة:** زر «مزامنة مع قت هب» بالصفحة — يرفع تصنيف هالجهاز ويجيب تصنيف أجهزتك الثانية. وقبل أي تحديث للبلقن زامن أول.
- **ملفات صوت جديدة:** بنسخة المستودع على جهازك الرئيسي، قل لكلود «ضيف الملفات الجديدة من مجلد الأصوات للمكتبة وارفعها».

# مونتاج حلال — Video edit (halal) + مكتبة الخلفيات الحلال

مستودع واحد **خاص** هو الأصل، ومنه يوصل البلقن لكل مكان:

| | كيف يوصله |
|---|---|
| **حسابك بـclaude.ai** | المستودع مضاف كمتجر بلقنات، و«Sync automatically» شغّال |
| **أي كمبيوتر تسجّل فيه** (الجهاز، اللابتوب) | ينزل من حسابك لحاله — Claude Code وتبويب Code بتطبيق الديسكتوب |
| **جلسات السحابة** (claude.ai/code) | تفتح الجلسة على هالمستودع نفسه — السكلات والأصوات موجودة فيه |

## وش فيه

| المجلد | البلقن | الحجم |
|---|---|---|
| `.claude/skills/` | **video-edit-halal** — 5 سكلات: الريل، الموشن، البودكاست، المونتاج، الكفر + أدوات المكتبة | ~24 ميقا |
| `halal-audio/` | **halal-audio** — 20 خلفية حلال بعلو موحّد ‎-16 LUFS + الفهرس | ~56 ميقا |
| `halal-sfx/` | **halal-sfx** — 33 مؤثر بلا موسيقى (ووش، bruh، شوك، كاميرا…) — فرز YAMNet + مراجعتك بأذنك | ~1 ميقا |
| `.claude-plugin/marketplace.json` | فهرس المتجر (يعرّف البلقنين) | — |
| `.claude/settings.json` + `cloud-setup.sh` + `CLAUDE.md` | تجهيز جلسة السحابة وتعليماتها | — |

> ⚠️ **خلّه خاص (Private).** الملفات الصوتية لها حقوق أصحابها — المستودع لاستخدامك الشخصي.

---

## ① ربط المستودع بحسابك (مرة وحدة)

1. افتح [claude.ai/customize/plugins](https://claude.ai/customize/plugins) (أو تطبيق الديسكتوب ← **Customize** ← **Plugins**).
2. **Add** ← **Add marketplace** ← اكتب: `Abo-qasim/video-edit-halal`
3. يطلب **Connect GitHub** / **Install the Claude GitHub App** ← وافق واختر مستودع **video-edit-halal** بس.
4. فعّل **Sync automatically**.
5. أضف البلقنات الثلاثة: **Video edit (halal)** و **Halal background audio** و **Halal sound effects**.
6. **شيل القديم** عشان ما تتكرر السكلات: `video-edit` و`video-edit-previews` (تحت **My Uploads**) ← **Remove**.

بعدها أي جهاز تسجّل فيه بنفس الحساب ينزّلهم لحاله عند أول جلسة (أو `/reload-plugins`).

## ② اللابتوب أو أي جهاز ثاني

- ثبّت [Claude Code](https://code.claude.com) أو تطبيق Claude للديسكتوب، وسجّل دخول **بنفس الحساب** — وخلاص.
- أول ما تطلب مونتاج، كلود يكمّل الأدوات (ffmpeg، بايثون…) بنفسه.
- **اختياري — مزامنة التصنيف من هالجهاز:** ثبّت [Git for Windows](https://git-scm.com/download/win) وشغّل مرة وحدة:
  ```bash
  git ls-remote https://github.com/Abo-qasim/video-edit-halal.git
  ```
  تطلع نافذة دخول قت هب ← سجّل. (بدونها التصنيف يشتغل بالجهاز، بس ما يرفعه للباقي.)

## ③ السحابة (من اللابتوب أو الجوال)

1. [claude.ai/code](https://claude.ai/code) ← اختر المستودع **video-edit-halal** ← ابدأ الجلسة.
2. السكلات والأصوات جاهزة، وffmpeg ينزل وحده أول الجلسة (~دقيقة).
3. **أسرع (اختياري):** بإعدادات البيئة ← *Setup script* ← الصق محتوى `.claude/cloud-setup.sh` (ينحفظ بالكاش).

- المقاطع: ارفعها بمجلد `work/<اسم>/` (commit من جهازك)، أو أعطه رابط تحميل مباشر. قت هب يرفض أي ملف فوق 100 ميقا.
- التسليم: كلود يحط الفيديو النهائي بفرع الجلسة، وتحمّله من قت هب.
- **أنسب شي للسحابة:** الموشن (من نص، بلا تصوير) والكفرات والمونتاج القصير. الثقيل على الكمبيوتر — أو تحكّم بجلسة جهازك من اللابتوب/الجوال بـ[Remote Control](https://code.claude.com/docs/en/remote-control).
- التفريغ بالسحابة قد يحتاج شبكة البيئة **Full** (تنزيل موديل وِسبر).

## 🎧 المكتبة

- **التصنيف بأذنك:** بأي كمبيوتر قل لكلود «افتح صفحة مكتبة الخلفيات» — هادئ · ملهم · حماسي · تأملي · ملحمي.
- **المزامنة:** زر «مزامنة مع قت هب» بالصفحة — يرفع تصنيف الجهاز ويجيب تصنيف الأجهزة الثانية.
- **ملفات صوت جديدة:** على جهازك الرئيسي قل لكلود «ضيف ملفات الأصوات الجديدة للمكتبة وارفعها»
  (يبنيها بالمستودع، يرفع إصدار halal-audio، ويدفع — وحسابك يوزّعها). ⚠️ البلقن ~56 من 200 ميقا.

## 🔔 المؤثرات
- كلود يحطها بنفسه بلحظات لها معنى (ووش على القطع، شوك على المفاجأة…) — أو قل له «حط bruh هني».
- أصوات جديدة؟ أرسلها له (ملف أو رابط): يفرزها بنموذج YAMNet (يشيل أي شي فيه موسيقى)، ويفتح لك صفحة «مقبول / مرفوض»، ويضيف المقبول.

## 🔄 التحديث

أي تعديل يندفع للمستودع ← حسابك يسحبه (Sync automatically) ← كل الأجهزة. تبيه الحين؟ **Customize ← Plugins ← Check for updates**.
لازم يتغيّر رقم `version` بـ`plugin.json` عشان الأجهزة تسحب النسخة الجديدة.

## 🛠️ بدون حساب claude.ai (احتياط)
على جهاز مسجّل بقت هب:
```bash
claude plugin marketplace add https://github.com/Abo-qasim/video-edit-halal.git

claude plugin install video-edit-halal@halal-video
```
```bash
claude plugin install halal-audio@halal-video
```
```bash

```

# مكتبة المؤثرات الحلال — الملفات

هالبلقن فيه **الملفات بس**: 37 مؤثر بلا موسيقى (فرز YAMNet + مراجعة المستخدم بأذنه)، ذروتها ‎-1 dBFS،
وفهرس `catalog.json` (التصنيف، المدة، نقطة الربط) بمجلد: `${CLAUDE_SKILL_DIR}/..`

**الأدوات والشرح ببلقن Video edit (halal)** — سكل `video-ad-editor`:
- `scripts/44_sfx_lib.py list` يطبعها · الريل: `sfx.json ← "lib"` · الموشن: `sfx.json ← type: "lib:…"`
- الخطوات ← `references/sfx-library.md`

`where` ما لقاها؟ مرّر `SFX_LIB="${CLAUDE_SKILL_DIR}/.."`.
⛔ لا تعدّل ملفات هالمجلد — نسخة من حسابه تنعاد مع كل مزامنة.
